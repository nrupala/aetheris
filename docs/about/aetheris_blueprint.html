Process / request lifecycle

1. Browser → Cloudflare Access — identity check at the edge; a signed Cf-Access-Jwt-Assertion is injected.
2. cloudflared tunnel forwards to the loopback service its hostname maps to (ingress table below).
3. For core routes, opa_gate runs: if *sensitive* (mutating verb, or GET of /keys /audit /sync/download /dev/logs), core verifies the JWT (RS256, pinned JWKS, iss + aud ∈ 5-AUD set). A verified email is the authoritative identity; missing/forged → denied.
4. OPA authorize (aetheris.authz / aetheris.agents, role-aware). Under OPA_ENFORCE=1 a deny → 403.
5. Dispatch to engines → Ollama (embed/chat) + vault (SQLite vectors/KG/WAL).
6. Decision observability: OPA decision_logs.console, metrics, audit/WAL.

Verified features — today

  • Zero-trust gateway: CF-Access identity + signed-JWT verify (5-AUD set, hourly key refresh); OPA enforcement LIVE (authz + agents packages, method-aware is_sensitive, fail-closed on sensitive routes).
  • AI Chat: OpenAI-compatible /v1/* proxy → Ollama (qwen2.5:7b live default; phi4-mini, qwen3:8b, qwen2.5-coder:7b available).
  • RAG: ingest (text/code + PDF→text) → nomic-embed-text 768-d → vectors.db; /query with top-k, /config (partial-merge), /sources, /stats, delete-with-cascade; embed-dim guard; rerank wired but disabled (no engine installed).
  • Agents: Planner→Researcher→Coder→Reviewer; /task/submit, /workflow/run, /agents*; OPA per-role allowlists; in-process model calls.
  • MCP & A2A: /mcp/tools (9 tools), /a2a/messages; oc-bridge exposes OpenCode API as read-only MCP (CF-JWT gated).
  • Data/ops: knowledge graph (knowledge_graph.db), WAL, Chronicle snapshots, audit log + replay, sync, keys, settings, coordinator circuits, orchestrator state/forecast, metrics/health.
  • Panels (zero-JS HTML, Host-header served): ai · agents · rag · dev (API console, RAG config/test, system) · guardian · settings.
Honest corrections (live check vs older docs): no ZFS (storage is ext4 on /data); no nginx (core serves panels by Host header); Docker installed but zero containers (fully native); no rerank engine yet (llama-server/llamafile absent); agents.* confirmed → core :8080; mgmt is a real separate service on :9090 (kept out of the core AUD set).
