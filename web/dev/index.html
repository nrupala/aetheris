Aetheris Dev Sandbox — Documentation

Overview

The Dev Sandbox provides a browser-based interface for exploring and testing all Aetheris API endpoints. It includes an API Console, live System Logs, configuration viewer, and service metrics dashboard.

Access

  • URL: https://dev.nrupalakolkar.com
  • Auth: Cloudflare Access (identity-gated; no static credentials)
  • Connection: Cloudflare Tunnel (encrypted, no open ports)

Tabs

  • API Console — Execute requests against any Aetheris endpoint with method/body control
  • RAG Config — Load, edit, and save RAG pipeline configuration (chunking, models, reranker)
  • RAG Query — Interactive query test with configurable top K, reasoning, and reranking
  • System — Service health dashboard with uptime, models, and RAG statistics

API Reference

All endpoints are accessible at https://dev.nrupalakolkar.com/

GET /api/health

Overall system health including agent count, task count, tools, prompts, and cross-system status.

GET /api/status

Detailed status of all services: WAL, knowledge graph, connect policy, OPA, and model endpoints.

GET /api/agents/status

Status of each agent in the pool: role, model, state (idle/executing/failed), tasks completed, policy checks.

GET /api/orchestrator/state

Cross-engine orchestration state showing all connected engines with memory, queue depth, and response times.

GET /api/orchestrator/forecast

Resource spread forecast with predicted memory usage, host utilization, bottleneck analysis, and recommendations.

GET /api/mcp/tools

List all available MCP (Model Context Protocol) tools with names, descriptions, and tags.

GET /api/a2a/messages

Agent-to-Agent (A2A) message log showing inter-agent communication flow, approval status, and timestamps.

GET /api/tasks

Recent tasks with IDs, descriptions, roles, agent IDs, status, and timestamps.

POST /api/query

Ask a question against indexed documents using RAG. Supports reasoning mode and confidence thresholds.

GET /api/sources

List all indexed RAG documents with chunk counts and last-seen timestamps.

GET /api/stats

RAG knowledge base statistics: total chunks, sources, and database size.

GET /api/knowledge-graph/stats

Knowledge graph statistics: entities, relations, interactions, and decisions.

GET /api/knowledge-graph/entities

List knowledge graph entities with type and importance scores, filterable by entity type.

GET /api/knowledge-graph/relations

List knowledge graph relationships showing entity-to-entity connections.

GET /api/coordinator/circuits

Circuit breaker states for each engine: closed (healthy), open (tripped), or half-open (recovering).

GET /api/v1/models

List available AI models from Ollama with IDs and metadata.

Architecture

Browser → Cloudflare Edge (Access) → Tunnel → Aetheris Core (:8080)
  → Rust Core (:8080) — API gateway, agents, file ops
    → Python Orchestrator (:9090) — RAG, KG, cross-system features (optional)
      → Ollama (:11434) — Local LLM inference

Related Services

  • AI: https://ai.nrupalakolkar.com — Direct LLM chat
  • Agents: https://agents.nrupalakolkar.com — Agent Orchestrator Dashboard
  • RAG: https://rag.nrupalakolkar.com — Document Q&A with retrieval

Infrastructure

  • Host: Windows Desktop (WSL2 Docker)
  • Tunnel: Cloudflare Tunnel v2
  • Access: Cloudflare Access (identity-gated)
  • Runtime: Rust Axum web server on port 8080
  • Orchestrator: Python FastAPI + Uvicorn on port 9090
  • AI Runtime: Ollama API server on port 11434
