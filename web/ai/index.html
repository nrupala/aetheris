Overview

Aetheris AI provides local LLM inference via LMStudio running on the host machine. All 21 models run locally with zero cloud dependency, ensuring complete data privacy.

Access

  • URL: https://ai.nrupalakolkar.com
  • Auth: HTTP Basic Auth — ai_user / efqbqFUzj841_r-5
  • Connection: Cloudflare Tunnel (encrypted, no open ports)

Architecture

Browser → Cloudflare Edge → Tunnel → Nginx (auth + proxy) → LMStudio (localhost:1234)
  • Inference Engine: LMStudio API server (OpenAI-compatible)
  • Models: 21 loaded models spanning coding, reasoning, and general purpose
  • Security: HTTP Basic Auth at nginx layer + Cloudflare encryption
  • Cost: $0/month — fully local, no API calls to external services

API Reference

All endpoints are OpenAI-compatible, accessible at https://ai.nrupalakolkar.com/v1/

GET /v1/models

List all loaded models with metadata.

curl -u ai_user:efqbqFUzj841_r-5 \
  https://ai.nrupalakolkar.com/v1/models

POST /v1/chat/completions

Generate chat completions with conversation history.

curl -u ai_user:efqbqFUzj841_r-5 \
  https://ai.nrupalakolkar.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "strand-rust-coder-14b-v1",
    "messages": [{"role": "user", "content": "Explain Rust ownership"}],
    "max_tokens": 4096,
    "temperature": 0.7
  }'

Usage Examples

Python

import requests
resp = requests.post(
    "https://ai.nrupalakolkar.com/v1/chat/completions",
    auth=("ai_user", "efqbqFUzj841_r-5"),
    json={
        "model": "strand-rust-coder-14b-v1",
        "messages": [{"role": "user", "content": "Hello!"}],
        "max_tokens": 100
    }
)
print(resp.json()["choices"][0]["message"]["content"])

cURL

curl -u ai_user:efqbqFUzj841_r-5 \
  https://ai.nrupalakolkar.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"strand-rust-coder-14b-v1","messages":[{"role":"user","content":"Hi"}],"max_tokens":50}'

OpenAI SDK

from openai import OpenAI
client = OpenAI(
    api_key="not-needed",
    base_url="https://ai.nrupalakolkar.com/v1"
)
# Add auth header via custom transport
resp = client.chat.completions.create(
    model="strand-rust-coder-14b-v1",
    messages=[{"role": "user", "content": "Explain Rust lifetimes"}]
)

Tips

  • Code tasks: Use strand-rust-coder-14b-v1 or qwen2.5-coder-14b
  • Reasoning: Use microsoft/phi-4-reasoning-plus
  • Fast responses: Use ibm/granite-4-h-tiny or google/gemma-3-1b
  • Conversation context: Chat UI maintains history automatically
  • Max tokens: Set higher for longer outputs (default 4096)
  • Temperature: 0.0 for deterministic, 0.7 for creative, 1.0 for maximum variety
