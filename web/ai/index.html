📘 Aetheris AI — Documentation

Overview

Aetheris AI provides local LLM inference via Ollama running on the host machine. All inference happens locally with zero cloud dependency, ensuring complete data privacy. The production server currently runs qwen2.5:7b as the single model.

Access

  • URL: https://ai.nrupalakolkar.com
  • Auth: Cloudflare Access (identity-gated; no static credentials)
  • Connection: Cloudflare Tunnel (encrypted, no open ports)

Architecture

Browser → Cloudflare Edge (Access) → Tunnel → Aetheris Core (:8080)
  → Rust Core (:8080) — API gateway, proxies /v1/* to Ollama
    → Ollama (:11434) — Local LLM inference (qwen2.5:7b)
  • Inference Engine: Ollama API server (OpenAI-compatible)
  • Current Model: qwen2.5:7b (14B parameter Qwen 2.5)
  • API Format: OpenAI-compatible /v1/chat/completions and /v1/models
  • Security: Cloudflare Access (identity-gated) + Cloudflare encryption
  • Cost: $0/month — fully local, no API calls to external services

API Reference

All endpoints are OpenAI-compatible, accessible at https://ai.nrupalakolkar.com/v1/

GET /v1/models

List available models with metadata.

curl -H "CF-Access-Client-Id: $CF_ACCESS_CLIENT_ID" -H "CF-Access-Client-Secret: $CF_ACCESS_CLIENT_SECRET" \
  https://ai.nrupalakolkar.com/v1/models

POST /v1/chat/completions

Generate chat completions with conversation history.

curl -H "CF-Access-Client-Id: $CF_ACCESS_CLIENT_ID" -H "CF-Access-Client-Secret: $CF_ACCESS_CLIENT_SECRET" \
  https://ai.nrupalakolkar.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen2.5:7b",
    "messages": [{"role": "user", "content": "Explain Rust ownership"}],
    "max_tokens": 4096,
    "temperature": 0.7
  }'

Usage Examples

Python

import requests
resp = requests.post(
    "https://ai.nrupalakolkar.com/v1/chat/completions",
    headers={"CF-Access-Client-Id": os.environ["CF_ACCESS_CLIENT_ID"], "CF-Access-Client-Secret": os.environ["CF_ACCESS_CLIENT_SECRET"]},
    json={
        "model": "qwen2.5:7b",
        "messages": [{"role": "user", "content": "Hello!"}],
        "max_tokens": 100
    }
)
print(resp.json()["choices"][0]["message"]["content"])

cURL

curl -H "CF-Access-Client-Id: $CF_ACCESS_CLIENT_ID" -H "CF-Access-Client-Secret: $CF_ACCESS_CLIENT_SECRET" \
  https://ai.nrupalakolkar.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen2.5:7b","messages":[{"role":"user","content":"Hi"}],"max_tokens":50}'

OpenAI SDK

from openai import OpenAI
client = OpenAI(
    api_key="not-needed",
    base_url="https://ai.nrupalakolkar.com/v1"
)
resp = client.chat.completions.create(
    model="qwen2.5:7b",
    messages=[{"role": "user", "content": "Explain Rust lifetimes"}]
)

Tips

  • Current model: qwen2.5:7b — general-purpose 14B parameter model, good for code, reasoning, and chat
  • Conversation context: Chat UI maintains history automatically
  • Max tokens: Set higher for longer outputs (default 4096, max 8192 for qwen2.5:7b)
  • Temperature: 0.0 for deterministic, 0.7 for creative, 1.0 for maximum variety
  • Streaming: Set stream: true in request body for token-by-token streaming
  • System prompt: Include a system role message to set behavior
