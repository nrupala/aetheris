Aetheris Agent Orchestrator

Overview

Multi-agent system with MCP server, A2A protocol, and cross-engine orchestration. Agents collaborate through a planner-coordinated workflow with OPA-gated access to RAG, KG, and file systems.

Agent Roles

  • Researcher — Queries RAG with reasoning loop, extracts entities to KG
  • Coder — Uses RAG context + KG for code generation
  • Reviewer — Evaluates against KG history + RAG standards
  • Planner — Decomposes tasks, coordinates multi-agent workflows

API

POST /workflow/run     — Run multi-agent workflow
POST /task/submit      — Submit single-agent task
GET  /agents/status    — Agent status
GET  /orchestrator/state  — Cross-engine state
GET  /orchestrator/forecast — Resource forecast
